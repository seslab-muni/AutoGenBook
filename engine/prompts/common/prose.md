Style of the document text:
- Continuous, precise prose organised in paragraphs separated by blank lines; do not hard-wrap lines.
- Explain mechanisms, assumptions, limitations and consequences instead of listing facts. Use lists only for genuine steps, short taxonomies or compact comparisons, and never nest them.
- Keep one term for one concept throughout, following the glossary when one is given.
- No chatty openings, no meta commentary ("In this section we will..."), no motivational filler, no summaries that merely repeat the section.
- Markdown only: emphasis, lists, tables, `code`, fenced code blocks and LaTeX math in `$...$` or `$$...$$`. No raw LaTeX commands or environments, no HTML.
